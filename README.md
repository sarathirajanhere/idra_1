# Simple Calculator 🧮

A beginner-friendly Python script that performs basic arithmetic operations on two user-provided numbers. Perfect for learning Python fundamentals like input handling, arithmetic operators, and formatted output.

## Features

- **7 Operations**: Addition, Subtraction, Multiplication, Division, Floor Division, Modulus, Exponentiation
- **Interactive Input**: Prompts user for two numbers
- **Clean Output**: Formatted results table with clear labels
- **Zero Dependencies**: Pure Python standard library

## Tech Stack

- **Language**: Python 3.x
- **Dependencies**: None (stdlib only)

## Installation

```bash
git clone https://github.com/sarathirajanhere/idra_1.git

```
